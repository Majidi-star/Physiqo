## ⚡ Features

1. **Cinematic Dark Design:** Fully tuned with premium design tokens: radial dark backgrounds (`#1C1C1E`), contrasting orange highlights (`#FF6B2C`), and high-end typography.
2. **On-Device Security (Serverless):** 100% private. All generated routines are saved locally. API keys are encrypted via `FlutterSecureStorage`.
3. **Smart Body Scan Analysis:** Capture pictures or vision assets to query Reka or Gemini for posture alignment, body-fat percentage estimation, and muscle weak points.
4. **Localized Database:** Hundreds of bodybuilding and resistance exercises mapped to muscle groups in the user's native language.
5. **Dynamic Injury Routing:** Filter out workouts putting strain on active injuries (e.g. knee pain, lower back disk) automatically.

## 🚀 Quick Start Guide

### Developer Prerequisites
* **Flutter SDK:** `^3.12.2` or later.
* **Dart SDK:** `^3.0.0` or later.
* **Device:** iOS or Android device/emulator.

### Setup and Running
1. Clone the repository:
   ```bash
   git clone https://github.com/Majidi-star/Physiqo.git
   cd Physiqo
   ```

2. Get package dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```
