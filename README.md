## ⚡ Key Features

1. **Cinematic Dark Design**  
   Designed with premium UI tokens (Deep Backgrounds, Orange Accents) and absolutely zero neon, glow, or shadows for a clean, focused, and professional aesthetic.

2. **100% Serverless & Private**  
   Physiqo runs entirely on-device. Your AI API keys (OpenAI, Anthropic, Gemini, etc.) are encrypted and stored locally via `FlutterSecureStorage`. No central servers, no data tracking.

3. **Multilingual & Auto-RTL Support**  
   Instantly switch between 11 supported languages (English, Persian, Chinese, Hindi, Spanish, Arabic, French, Bengali, Portuguese, Russian, Urdu) with perfect layout mirroring for Right-To-Left (RTL) languages.

4. **Body Scan & Vision Analysis**  
   Use your device's camera to capture your posture and physique. The AI coach analyzes your alignment and identifies weak points directly from your photos.

5. **Dynamic Injury Profiling**  
   Tell the app about your injuries or limitations. The AI will dynamically adjust your workout plans, swapping out risky exercises for safe, joint-friendly alternatives.

## 🚀 Quick Start

To run the app locally, ensure you have [Flutter](https://flutter.dev/docs/get-started/install) installed, then execute:

```bash
# Get dependencies
flutter pub get

# Run the app
flutter run
```

## 🛠 Tech Stack
- **Framework:** Flutter (Dart)
- **Architecture:** 100% Client-Side / Serverless
- **Storage:** Local Encrypted Storage (`FlutterSecureStorage`)
- **AI Integration:** Bring Your Own Key (BYOK) - Supports OpenAI, Anthropic, Google Gemini, and custom endpoints.
